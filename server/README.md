# DesireMes API

Node.js 24+ (используется встроенный node:sqlite). Дополнительных npm-зависимостей нет.

В корне проекта, в двух терминалах:

```powershell
npm run server
```

```powershell
npm run tauri dev
```

Регистрация: логин (3–32 латинских символа, цифры, _) и пароль (12–128 символов).
Старые демонстрационные профили не являются серверными аккаунтами.
Старая локальная база messenger_v2.db остаётся нетронутой. Автоматического импорта
нет: назначение владельцев старой истории требует отдельного решения.

## Структура

- schema.sql — новая серверная база, без демонстрационных пользователей.
- database.mjs — подключение и публичные поля пользователя.
- dialogs.mjs — личные диалоги, группы, участники и порядок списка.
- channels.mjs, routes/channels.mjs — каналы, подписки, комментарии и права владельца.
- appearance.mjs — настройки оформления каждого аккаунта.
- security.mjs — scrypt, токены и проверка входных данных.
- app.mjs — HTTP API, CORS и проверка сессий.
- routes/ — отдельные обработчики авторизации, профиля и чатов.
- http.mjs, uploads.mjs — проверка запросов и безопасная загрузка изображений.
- index.mjs — запуск.
- test/accounts.test.mjs — интеграционные тесты с отдельной временной базой.
- ../src/services/api.ts — единый клиент API.
- ../src/composables/useAccounts.ts — сессии и сохранённые аккаунты.
- ../src/composables/useChats.ts — серверные чаты, чтение и сообщения.

## Размещение на сервере

По умолчанию API слушает только 127.0.0.1:3001. Для внешнего доступа нужен HTTPS
reverse proxy (например Caddy), постоянный диск и ограниченный доступ к SQLite.
Нельзя выставлять этот HTTP-порт напрямую в интернет.

Переменные процесса сервера:

- HOST — адрес прослушивания (по умолчанию 127.0.0.1).
- PORT — порт (3001).
- DATABASE_PATH — полный путь к БД (server/data/messenger.db).
- ALLOWED_ORIGINS — список разрешённых Origin через запятую. По умолчанию
  localhost:1420 и Origin Tauri; не используйте wildcard.

Для клиента задайте VITE_API_URL=https://your-api.example в .env.local
и добавьте этот точный HTTPS Origin в connect-src (csp и devCsp) файла
src-tauri/tauri.conf.json, затем пересоберите. Секретов в переменной нет.
Удалённые HTTP-адреса клиент запрещает.
При запуске сервера из другого рабочего каталога явно задавайте DATABASE_PATH.

## Сессии и ограничения

Пароли хешируются scrypt (N=131072, r=8, p=1) с индивидуальной солью.
В базе хранится SHA-256 от случайного 256-битного токена, не сам токен.
Сессии истекают через 30 дней, выход отзывает текущую сессию.
На Windows сохранённые сессии клиента шифруются DPAPI для пользователя ОС.
В браузерном предпросмотре они только в памяти, после перезагрузки нужен новый вход.
На других ОС необходимо подключить защищённое системное хранилище.

Поиск по имени и @логину открывает личный диалог. Получатель увидит диалог после
первого сообщения. Переписка и вложения доступны только участникам.
Закрепление, заглушение и выбранный чат хранятся отдельно для каждого аккаунта.
Удаление скрывает диалог и очищает видимую историю только у текущего пользователя.
Новые сообщения возвращают диалог; старая история у собеседника не изменяется.
Старые общие чаты сохранены в базе как архив, но через API больше не доступны.
Светлая, тёмная и системная темы, акцент, размер текста, фон и компактный список
сохраняются автоматически в серверном профиле. Настройки доступны в меню и вкладке «Внешний вид».
Меню находится слева рядом с поиском, общей верхней панели больше нет.
«Создать группу» позволяет выбрать название и до 99 других пользователей.
Группа появляется у всех участников сразу; сведения об участниках — по нажатию
на заголовок группы. Доступ к сообщениям и вложениям проверяется по участию.
Удаление группы из списка, как и диалога, очищает только вашу видимую историю;
оно не удаляет группу у остальных и не является выходом из группы.
Старая таблица участников автоматически переносится без потери данных при
перезапуске API. Проверка миграции находится в test/groups.test.mjs.
Разделители дат используют местную часовую зону клиента. Нажатие открывает
выбор дня и переход внутри последних 500 загруженных сообщений.
После обновления перезапустите процесс API, чтобы он создал новые таблицы.
Телефонной регистрации, восстановления пароля и двухфакторного входа пока нет.
Нельзя считать текущую версию полноценным аналогом Telegram: нет E2E-шифрования,
push-уведомлений, модерации, резервного копирования и аудита безопасности.
Вложения до 8 МБ, аватары до 2 МБ; доступ к ним требует сессии.
Квота хранения вложений — 64 МБ на аккаунт; очистка старых файлов пока ручная.
Последние 500 сообщений загружаются при открытии чата; обновление раз в 3 секунды.
Для публичного запуска настройте резервное копирование, мониторинг, лимиты
reverse proxy, квоты диска, восстановление доступа и проведите security review.

Тесты: npm run test:server.

Каналы: POST /api/channels — создать, GET /api/channels?q=... — искать;
GET/PATCH /api/channels/:id — информация/управление;
POST/DELETE /api/channels/:id/subscription — подписка/отписка.
Посты используют /api/chats/:id/messages, публикация разрешена только владельцу.
GET/POST /api/posts/:id/comments — обсуждение поста;
PATCH/DELETE /api/comments/:id — изменение своего комментария и удаление своего
или, для владельца канала, любого комментария. Проверки выполняются на сервере.
Неподписанный пользователь видит только публичную информацию и аватар, но не посты
и обсуждения. Подписчикам не выдаётся список других подписчиков.
channel_views хранит уникальные просмотры загруженной истории, без накрутки при опросе.
message_sequence не позволяет повторно использовать ID удалённых постов и нарушать
состояние прочитанного. Новые таблицы создаются при запуске без удаления старых данных.
