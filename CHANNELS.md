# Каналы мессенджера - этап 1

Учебный проект подготовлен с помощью ИИ. В карточке указана только тема;
пользователь разрешил выбрать проект. Развивается существующий Vue/Tauri чат.

Этап 1: создание уникального канала (название 1-60 символов, описание до 200),
выбор канала, независимая история сообщений и сохранение в SQLite.
Миграция 3 сохраняет старые сообщения в канале «Общий»; индекс ускоряет выборку.
Все значения передаются SQL-параметрами. Устаревший ответ загрузки не заменяет
сообщения уже выбранного другого канала. Черновик очищается после успешной записи.

Запуск: `npm install`, `npm run tauri dev` (нужны Rust и инструменты сборки Tauri).
`npm run build` проверяет TypeScript и frontend. В обычном браузере Tauri SQL
недоступен: для проверки сохранения нужен desktop-запуск.

Ручная проверка: создать «Учёба» и «Проекты», написать сообщения в каждом,
переключить и перезапустить приложение. Истории должны быть независимы,
а старая история оставаться в «Общий». Повтор имени должен показать ошибку.

Ограничение: это локальный учебный мессенджер без сетевого сервера и настоящей
аутентификации. Интеграционный desktop-тест не выполнен; не выдаётся за выполненный.
