# DesireMes

Серверные аккаунты, профили, персональное оформление, личные диалоги, группы и каналы.
Клиент: Tauri + Vue + TypeScript.
API: Node.js 24+ и отдельная SQLite.

В корне проекта запустите `npm run server`, затем в другом терминале
`npm run tauri dev`. Для создания аккаунта нажмите «Создать аккаунт».

Подробности запуска, хранения данных, безопасности и размещения:
[server/README.md](server/README.md).

Проверки: `npm run build`, `npm run test:server`,
`cargo test --lib account_vault` из папки src-tauri.

Старая локальная история не удаляется и автоматически на сервер не импортируется.

Меню открывается кнопкой рядом с поиском слева. В нём можно создать группу:
задать название и найти участников по имени или @логину (до 100 вместе с создателем).
Нажатие на заголовок группы показывает её участников.
Внешний вид применяется сразу и автоматически сохраняется после 450 мс без изменений;
запросы выполняются последовательно, повторяющиеся значения не отправляются.
Закрытие настроек сохраняет ожидающие изменения. При ошибке доступен повтор.
В сообщениях показывается только местное время; даты вынесены в закрепляющиеся
разделители. Нажмите на дату для перехода по дням в загруженной истории (последние 500 сообщений).

## Каналы

В боковом меню выберите «Создать канал». Название, описание, аватар и уникальный
@адрес можно менять через заголовок канала → «Управление каналом».
Каналы публичные: поиск по названию или @адресу позволяет открыть информацию
и подписаться. Посты с текстом, изображениями, стикерами и GIF публикует только
владелец, от имени канала; доступно изменение и удаление своих постов.
Подписчики обсуждают каждый пост в отдельной панели комментариев. Свой комментарий
можно изменить и удалить; владелец может удалять любые комментарии и отключать
новые комментарии в настройках. Удаление поста удаляет его обсуждение.
Отписка выполняется с подтверждением в информации о канале и прекращает доступ
к его постам. Просмотры считаются по уникальным аккаунтам, загрузившим историю.
Обновление постов и открытого обсуждения — каждые 3 секунды. Загружаются последние
500 постов и 500 комментариев. Приватных каналов, назначения администраторов,
планирования публикаций и древовидных ответов пока нет.

После обновления перезапустите API (`npm run server`), чтобы добавились таблицы;
существующие чаты и сообщения не удаляются.
